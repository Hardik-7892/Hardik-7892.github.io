My software engineering foundation comes from nine months inside a production MLOps platform at Samsung Electro-Mechanics. I built and integrated the internal pado_mlops Python package to automate pipeline deployment end-to-end, managed Kubernetes clusters and container image repositories across dev and prod (JFrog, Harbor), and kept the platform observable with Prometheus and Grafana. Real users, real deployments, real incidents.

I learn best by shipping. install-k8s-tui is a Rust TUI that generates ready-to-run Kubernetes install scripts across five distributions — a single zero-dependency binary with cross-platform releases and GitHub Actions CI/CD. emojinterp is a full esoteric-language interpreter in Rust, from lexing to execution. This site itself is ~5,500 lines of vanilla HTML/CSS/JS, and shutterfolio is a JAMstack app with a GitHub-API-backed admin panel.

I care about the parts of engineering that aren't glamorous but are what make software reliable: unit and integration testing, code coverage, root-cause analysis, and documentation that actually gets read. At Samsung I wrote the user manual and built the admin manual from scratch — working from Korean drafts.
