Certificate Verification

Post-quantum signatures (ML-DSA-87, NIST FIPS 204) verified entirely in your browser.

Paste a certificate JSON below and click Verify, or open the page with a link that already contains one:

  • Paste JSON (the text box above)
    Paste any certificate you have as a file and click Verify.
  • ?id=<certificate id> (short link)
    The certificate ID is a 16-character hash of the claims, printed on the certificate. The page fetches the hosted copy from issued/<id>.json.
  • ?c=<full certificate> (long link)
    The entire certificate is packed into the link. The page decodes and verifies it directly, with no download, even if the hosted copy is later removed.
